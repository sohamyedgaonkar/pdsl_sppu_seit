# PDSL SPPU SEIT Assignments

Two standalone C assignment programs are included: `newmain_ass1.c` and `newmain_ass2.c`. The repository also contains `ass_1_output.odt` as a submitted/output document.

Compile an assignment with a C compiler, for example:

```bash
gcc newmain_ass1.c -o ass1
./ass1
```

Repeat with `newmain_ass2.c` to build the second program. The programs may prompt for input; follow their on-screen instructions.
